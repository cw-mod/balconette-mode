CatWar Balconette

Модульный юзерскрипт для игровой CatWar: сетка, поле для ЛУ, ID во рту, звуки, часы и другие улучшения. Каждый модуль включается отдельно в одной панели.

Установить в Tampermonkey

Версия 0.1.2 Автообновление: catwar-balconette.meta.js. Исходники: github.com/cw-mod/balconette-mode.

Установка

  1. Установите Tampermonkey.
  2. Нажмите «Установить в Tampermonkey» — расширение предложит добавить скрипт.
  3. Отключите старые моды: CW Shed, CatWar UwU, CW Mod. Вместе с ними чат и поле ломаются.
  4. Откройте игровую https://catwar.su/cw3/. В углу появится кнопка «⚙ моды» (или Ctrl+Alt+B).

После установки Tampermonkey сам проверяет обновления с этой страницы. Проверить вручную: Tampermonkey → Balconette → «Проверить обновления».
