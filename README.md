# CatWar Balconette

Модульный юзерскрипт для браузерной игры [CatWar](https://catwar.su/cw3/).
Все улучшения — отдельные модули, включаются и выключаются в одной панели
прямо на странице, без перезагрузки.

**Установка:** [cw-mod.github.io/balconette-mode](https://cw-mod.github.io/balconette-mode/)

Репозиторий организации: [github.com/cw-mod/balconette-mode](https://github.com/cw-mod/balconette-mode).
Техническое задание — в [`SPEC.md`](SPEC.md).

---

## Установка в Tampermonkey

1. Установить расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Открыть [страницу установки](https://cw-mod.github.io/balconette-mode/) и нажать **«Установить в Tampermonkey»**.
3. **Отключить старые моды** — CW Shed, CatWar UwU, CW Mod. Совместимость с ними
   не поддерживается, и именно они ломали поле ввода чата.
4. Открыть `https://catwar.su/cw3/`. В углу появится кнопка-шестерёнка.

Прямая ссылка на скрипт: [catwar-balconette.user.js](https://cw-mod.github.io/balconette-mode/catwar-balconette.user.js).
Скрипт для ЛУ: [catwar-balconette-lu.user.js](https://cw-mod.github.io/balconette-mode/catwar-balconette-lu.user.js).

### Обновление

В шапке скрипта стоят `@updateURL` и `@downloadURL` на GitHub Pages.
Tampermonkey сам подтягивает новые версии (обычно раз в сутки). Проверить сразу:
меню расширения → CatWar Balconette → «Проверить обновления».

После правки исходников поднимите `@version` в `src/header.txt` и `src/header-lu.txt`, соберите
`node build.js` и запушьте — страница установки и метафайл обновятся вместе с бандлом.

### Панель настроек

- Кнопка-шестерёнка в углу экрана, либо **Ctrl+Alt+B**.
- Модули сгруппированы по категориям, есть поиск.
- У модуля с настройками — иконка ⚙ рядом с переключателем.
- Внизу — **Экспорт настроек** / **Импорт настроек** (JSON-файл).
- Раздел **Ядро**: положение кнопки, горячая клавиша, уровень логов в консоли,
  экспериментальный хук сокета.

Все настройки по умолчанию выключены: после установки скрипт ничего не меняет,
пока вы сами не включите нужные модули.

## Модули

### Партия 1 — оформление и простая логика

| Модуль | Что делает |
|---|---|
| Всегда день | Убирает ночное затемнение поля; опционально дневное небо |
| Сетка на поле | Границы клеток: цвет, прозрачность, толщина |
| Статичный фон | Свой цвет или картинка вместо фона локации и/или сезонного скина |
| Убрать погоду | Раздельно: небо, температура, час, сезон |
| Подсветка переходов | Свечение перехода при наведении |
| Часы | Плавающий виджет: местное/МСК время, игровой час и сезон |
| Автопрокрутка истории | Держит историю прокрученной к последней записи |
| Старые иконки действий | Подмена картинок кнопок действий (нужны свои картинки, см. SPEC §6.1) |

### Партия 2 — данные, звук, охота

| Модуль | Что делает |
|---|---|
| Координаты клетки | Подсказка x,y (и ярус дерева) при наведении на поле |
| Информация о параметре | Карточка по клику: значение, максимум, уровень и абсолютный опыт навыка |
| ID котов во рту | Числовой ID на иконке каждого кота во рту |
| ID предметов во рту | Уникальный ID, тип и название на предметах во рту |
| Копирование ID | Клик копирует ID в буфер (рот, «Уникальный ID», ссылки на профиль) |
| ID в личных сообщениях | `[id]` рядом с ником на странице `/ls` |
| Поменять кот ↔ действия | Сначала выбор соседнего кота (#mit), затем иконки действий |
| Звуки событий | Синтезированные звуки на ЛС, упоминание, конец действия и т.д. |
| Уведомления | Браузерные уведомления о ЛС и упоминании в чате |
| Подсказка по запаху (охота) | На `/cw3/jagd`: «Ближе» / «Дальше» / «Потерян» по цвету квадрата запаха |

Страница охоты `/cw3/jagd` поддерживается роутером; сетка и координаты клетки работают там, где поле — таблица `#cages` (на самой охоте разметка другая).

## Скрипт для ЛУ

`catwar-balconette-lu.user.js` — отдельная сборка для лазательных умений на основе того же ядра.
Настройки — одна страница без вкладок, у модулей нет кнопки сброса.

| Что внутри | Модуль |
|---|---|
| Минное поле 10×6 с вкладками и локациями, кач ЛУ, цифры по треску, перенос пометок на игровое поле (чекбокс прямо в панели) | Поле для ЛУ |
| Координаты клетки при наведении | Координаты клетки |
| Сначала выбор соседнего кота, потом иконки действий | Поменять кот ↔ действия |
| Старые картинки на кнопках действий (без настроек источника) | Старые иконки действий |
| История прокручена к последней записи | Автопрокрутка истории |
| `[id]` рядом с ником в личных сообщениях | ID в личных сообщениях |
| Уведомления о ЛС и упоминании: звук всегда, громкость 0–1, кнопка «Проверить звук» | Уведомления |
| Редирект catwar.net → .su (включён по умолчанию) и обратный catwar.su → .net (выключен; если включить оба, работает net → .su) | Редиректы |
| Свой цвет или картинка вместо фона локации | Статичный фон |
| Прячет температуру, час и сезон над полем | Убрать погоду |

## Сборка

Нужен только Node.js. Внешних зависимостей нет — ни в сборке, ни в рантайме.

```bash
node build.js            # dist/ + docs/ (страница GitHub Pages)
node build.js --watch    # пересобирать при изменении src/
npm run check            # сборка + node --check
```

Сборщик проверяет синтаксис до записи. Бандл, метафайл автообновления и копии для Pages
пишутся в `dist/` и `docs/`.

## Проверка без игры

Сайт разрывает сессию, если игра открыта во второй вкладке, поэтому для проверки модулей
есть заглушка.

```bash
node build.js
open test/mock.html     # или просто открыть файл в браузере
```

`test/mock.html` содержит имитацию игровой вёрстки (`#cages`, `#cages_div`, `#tr_sky`,
`#ist`, `#chat_form`, `#akten` и т.д.) и фейковый `#app.__vue__` с теми же модулями
стейта, что у игры (`weather`, `field`, `chat`, `cat`, `parameter`, …).
`$watch` в заглушке реализован опросом раз в 200 мс.

Мок-пульт справа сверху умеет переключать день/ночь, дописывать историю и сообщения,
крутить игровой час и пересобирать поле.

### Автоматический дымовой тест

Тот же мок можно прогнать без браузера — в jsdom:

```bash
npm i --no-save jsdom
npm run smoke
```

Тест проверяет, что скрипт стартует без исключений, панель монтируется в свой контейнер,
модули включаются и выключаются на лету, после выключения не остаётся ни `<style>`,
ни своих узлов, и что игровой DOM чата (`#chat_msg`, `#chat_form`, `input#text`) не тронут.

`jsdom` намеренно не в зависимостях: в рантайме и в сборке у проекта зависимостей нет.

## Как добавить свой модуль

Полная инструкция и шаблон — в [`SPEC.md`](SPEC.md), разделы 4.4 и 4.5. Коротко:

1. Создать `src/modules/<id>.js`.
2. Экспортировать объект-описание:

```js
module.exports = {
  id: 'my-feature',
  title: 'Моя фича',
  description: 'Что она делает.',
  category: 'field',            // field | interface | info | chat | sound | misc
  pages: ['game'],
  defaults: { color: '#ffffff' },
  schema: [{ key: 'color', type: 'color', label: 'Цвет' }],

  styles: function (s) {
    return '#cages td.cage { outline: 1px solid ' + s.color + '; }';
  },

  init: function (ctx) {
    // ctx.on / ctx.observe / ctx.watch / ctx.interval / ctx.mount —
    // всё снимается автоматически при выключении модуля
  },
};
```

3. `node build.js`. Модуль подхватится автоматически: ничего регистрировать в списках не нужно.

Если фича выражается одним CSS-правилом, хватит `styles()` — `init` можно не писать.

## Чего скрипт принципиально не делает

- **Ничего не отправляет на сервер.** Только чтение стейта и изменение отображения.
- **Не трогает DOM чата:** не прячет `#chat_msg`, не переносит `#chat_form`, не подменяет
  `input#text`. Именно на этом ломался ввод у старых модов.
- **Не открывает вторую вкладку игры** — сайт это детектит и рвёт сессию.
- **Не монтируется внутрь игровых контейнеров** — только свой `#cwb-root` в конце `<body>`.
- Не использует jQuery и `DOMNodeInserted`.

Полный список ограничений — в `SPEC.md`, раздел «Красные линии».

## Соседство с другими скриптами

Единственный поддерживаемый сосед — собственный скрипт пользователя «досье агентства»
(`detective-agency-overlay.user.js`). Он занимает префикс id `cwa-da-*` и ключ
`localStorage["cwa-da-ui-v1"]`; мы используем `cwb-` и `cwb:`, пересечений нет.
